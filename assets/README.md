# Animated SVG Assets

- `diwas-orbit.svg` is an animated identity graphic using SVG motion primitives for the orbit lines, pulse, and status light.
- `portfolio-flow.svg` is an animated path graphic connecting the portfolio themes: bots, automation, apps, APIs, and AI/ML.

Both files are dependency-free, scale cleanly, and can be embedded directly in Markdown, HTML, or a future project card.
